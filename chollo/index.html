Chollo & Glam

Joyería y artesanía peruana de diseño exclusivo. Proyecto completo de tienda online con panel de administración, pagos, moderación de contenidos y configuración visual (logo + carrusel de banners) sin tocar código.

Características

🛍️

Tienda SSR

Carrusel de banners a pantalla completa, ofertas flash con cuenta regresiva, destacados, categorías, colecciones, búsqueda y ficha de producto con valoraciones moderadas y SEO (JSON-LD).

🛒

Carrito y checkout

Carrito con animación al añadir, checkout profesional con datos de envío y métodos de pago (Tarjeta / PayPal / Transferencia) y página de confirmación de pedido.

🔐

Admin separado

Panel con login propio y diseño independiente: dashboard con estadísticas e ingresos netos, CRUD de productos, categorías, colecciones y ofertas flash.

💳

Pagos profesionales

Registrar, aprobar, fallar y reembolsar transacciones. Estado de pago del pedido automático (pendiente / parcial / pagado / fallido / reembolsado) con trazabilidad.

🖌️

Banners y logo

Desde el admin se cambia el logo de la tienda y se gestiona el carrusel de banners (vídeo/imagen/enlace) con guía de tamaños y márgenes.

👥

Usuarios y moderación

Roles admin / moderador / cliente, moderación de valoraciones y comentarios, notificaciones y bandeja de mensajes de contacto.

Cómo ejecutar

El proyecto es una app SSR con SQLite, por lo que se ejecuta con un servidor Node (no es estático). Instala, genera la base de datos con datos de ejemplo y arranca:

# en la carpeta web/
npm install
node scripts/seed.mjs   # crea data/chollo.db con datos demo
npm run dev             # → http://localhost:4321

Producción: npm run build → npm run preview.
